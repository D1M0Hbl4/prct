## Введение

Практика проходила по двум направлениям: инженерно-техническая эксплуатация аппаратно-программных средств БВС и научно-исследовательская работа по технологии гальванической вестибулярной стимуляции (ГВС) для повышения реалистичности авиационных симуляторов.

## Раздел 2. ЭКСПЛУАТАЦИЯ И ОБСЛУЖИВАНИЕ АППАРАТНО-ПРОГРАММНЫХ СРЕДСТВ

### 2.1. Выполнение стандартных работ инженера (под руководством специалиста)
- Внешний осмотр, проверка кабелей, контроль заряда батарей.
- Подключение и калибровка GPS, телеметрии, ESC и датчиков через Mission Planner.

### 2.2. Техническая эксплуатация АПС
- Конфигурирование и обновление прошивки полётного контроллера.
- Настройка PID-коэффициентов и параметров полёта.
- Настройка телеметрического канала и резервное копирование конфигураций.

### 2.3. Техническое обслуживание, профилактика и текущий ремонт
- Профилактика: очистка контактов, проверка креплений, обновление ПО на наземной станции.
- Ремонт: восстановление кабеля питания, замена разъёма JST на плате распределения питания.

### 2.4. Оперативный контроль технического состояния
- Мониторинг телеметрии в реальном времени (напряжение, ток, GPS, высота, скорость).
- Анализ логов полёта (Dataflash Logs) в Mission Planner для выявления ошибок.
- Оценка качества радиосигнала (RSSI).

### 2.5. Техническое обслуживание пульта
- Внешний осмотр, проверка аккумуляторов и контактов.
- Калибровка джойстиков через Mission Planner.
- Обновление прошивки пульта (OpenTX/EdgeTX).

## Раздел 4. ПРОГРАММИРОВАНИЕ, МОДЕЛИРОВАНИЕ И СИМУЛЯЦИЯ

### 4.1. Исследование исходного кода полётного контроллера flix
- Проанализирована структура проекта (src/, lib/, config/, drivers/).
- Изучены главный цикл управления, PID-регуляторы и фильтрация данных с датчиков.
- Составлена структурная схема работы контроллера.

### 4.2. Моделирование полёта flix в симуляторе Gazebo
- Установлена модель квадрокоптера в формате URDF/SDF.
- Выполнены тестовые запуски: взлёт, зависание, перемещение, реакция на возмущения.
- Проверена работа PID-регуляторов в виртуальной среде.

### 4.3. Компиляция проекта Gazebo
- Произведена сборка Gazebo из исходных кодов с использованием CMake и make.
- Устранены ошибки, связанные с отсутствием библиотек (Ignition Math, protobuf).
- Получен исполняемый файл симулятора.

### 4.4. Изучение производственного цикла изготовления ПАК
- Рассмотрены этапы: проектирование, изготовление платы, монтаж SMD/DIP, пайка (оплавление/волна), контроль качества (AOI, ICT).

### 4.5. Моделирование полёта в системе координат ENU
- Изучено отличие ENU (Z-вверх) от NED (Z-вниз).
- Выполнена настройка Gazebo для отображения траектории в ENU.
- Проведена визуализация полёта с преобразованием координат.

### 4.6. Соревнование Drone Code Arena
- Разработан алгоритм планирования маршрута с обходом препятствий (A* или RRT).
- Алгоритм учитывал ограничения по скорости и маневренности.
- Получен опыт скоростной разработки в условиях соревнования.

### 4.7. Изучение полётного контроллера Ardupilot и Mission Planner
- Изучена архитектура Ardupilot и режимы полёта (Stabilize, Loiter, RTL, Auto).
- В Mission Planner создана миссия: расстановка точек маршрута, настройка высоты и скорости.
- Миссия загружена в контроллер и выполнена в симуляции.

### 4.8. Установка и изучение ROS
- Установлена ROS (Noetic/Melodic) на рабочую станцию.
- Изучены узлы, топики, сервисы, параметры.
- Выполнена интеграция ROS с Gazebo: управление дроном через топик /cmd_vel.

## Раздел 5. НАУЧНО-ИССЛЕДОВАТЕЛЬСКАЯ РАБОТА ПО ГАЛЬВАНИЧЕСКОЙ ВЕСТИБУЛЯРНОЙ СТИМУЛЯЦИИ (ГВС)

### 5.1. Теоретический анализ и патентный поиск
- Изучена технология ГВС: воздействие малым током (0.5–4 мА) через электроды за ушами для создания иллюзии движения.
- Проанализированы существующие исследования по повышению реалистичности симуляторов (визуальные, тактильные, двигательные, нейрофизиологические методы).
- Проведён патентный поиск в базах Google Patents, Espacenet, Роспатент по теме ГВС и тренажёрных систем.

### 5.2. Физиологические эффекты и обработка данных
- Изучено влияние ГВС на вестибулярный нерв: анодная стимуляция — возбуждение, катодная — торможение.
- Собраны и предварительно обработаны экспериментальные данные (очистка от шумов, фильтрация).

### 5.3. Моделирование и интеграция
- Адаптирована математическая модель восприятия движения (модель Oman-Merfeld) с учётом внешнего воздействия ГВС.
- Разработан прототип алгоритма интеграции ГВС в архитектуру симулятора: симулятор → модель восприятия → вычисление параметров стимуляции → управляющий сигнал на электроды.
- Реализация выполнена на Python с использованием ROS-интерфейса.

### 5.4. Оценка эффективности
- По литературным данным, ГВС повышает субъективную реалистичность на 30–40%.
- Снижается количество ошибок пространственной ориентации при манёврах.
- Сформулированы рекомендации по применению ГВС в тренажёрных системах.
